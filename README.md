# FAM — Future Archives Modern

Native digital archive foundation for `archives.dmndx.live`.

## Included
- Next.js 15.4.6 + React
- FAM archival visual system
- Native record creation UI
- Declaration workflow
- Draft → sealed/archive lifecycle
- Version-aware record model
- Originality classes: native, deposited, digitized
- Supabase schema prepared for versions, sources, provenance events, and future audio/AI-mic originals

## Run
```bash
npm install
npm run dev
```

## Product principle
FAM does not claim that a digital record is physically handwritten or government-issued. It records the source type and provenance of the object actually deposited.

A native record is created directly inside FAM. A future AI-mic workflow can preserve the original audio, transcript, and derived document as linked but distinct archival objects.
